# notes nextjs express

simple notes app without login

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Next.js static export. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- an Express service in TypeScript. No architecture had been
  approved when this repository was created, so it starts with its health check
  and nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
npm install
npm run dev
npm test
npm run lint
npm run format
```
